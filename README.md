# CODSOFT

A responsive single‑page portfolio website showcasing Aamir Ahamed — Web Developer & AI Enthusiast. Built with plain HTML and CSS, the site features an animated hero, social icons (Font Awesome), a resume button, and sections for About, Education, Projects, and Contact.

## Features
- Clean, single-page layout with navigation
- Animated headings (slide-in effect)
- Social icons using Font Awesome
- External logo image and resume button
- Simple, easy-to-edit HTML/CSS structure ready for static hosting

## Tech stack
- HTML
- CSS
- Google Fonts (Poppins)
- Font Awesome (via CDN)

## Project structure
- index.html — main markup (navigation, hero, logo, social/connect, About section)
- style.css — styling (flexbox layout, animations, colors, spacing)

## Usage / Run locally
1. Clone the repository:
   git clone https://github.com/AamirAhamed07/CODSOFT.git
2. Open the project folder and open index.html in your browser (double-click or right-click → Open with → Browser).
3. Edit content in index.html and styles in style.css to customize.

## Deployment
This is a static site and can be deployed to any static host:
- GitHub Pages: Settings → Pages → select branch (main) and root → Save. Example URL: https://AamirAhamed07.github.io/CODSOFT/
- Netlify, Vercel, or any other static host will also work.
